# 2026-08-21 · 변경 이력 내보내기(`docs/CHANGELOG.md`) — 조사 세션 요청서

**상태**: Master 승인함 (2026-08-21). 개발 세션 착수 요청.
**제안자**: 개발 세션 (2026-08-21, Master 경유). 조사 세션은 승인 내용을 문서로 남기는 역할만 한다.

## 1. 무엇을

`git log` 를 사람이 읽는 평문으로 `minigames/docs/CHANGELOG.md` 에 내보낸다. 형식은 제안 그대로.

```
2026-08-21 6f4d9da  문서 없던 아케이드 6종의 규칙을 코드에서 받아 적는다
2026-08-21 0f4de0c  커버·썸네일도 sync 스크립트가 올린다
2026-08-20 e8085d5  웹툰 R2 버킷을 APAC 로 옮긴다
```

## 2. 왜

- 조사 세션은 `git` 을 실행하지 않는다(2026-08-01 Master 승인). **규칙을 건드리지 않고** 「누가·무엇을·언제·왜」가 읽힌다.
- 더 중요한 이유: **Cowork 기획 세션에는 셸도 파일시스템도 없다.** git 이 풀리든 말든 그 세션은 `git log` 를 못 쓴다.
  평문 파일은 프로젝트에 올릴 수 있어 **세 종류 세션이 전부 같은 이력을 본다.** git 은 셸이 있는 세션만 본다.

## 3. 착수 전 확인할 것 하나 — 배포가 한 번 더 돈다

`minigames/CLAUDE.md:153` — *"문서만 바꾼 커밋도 push 하면 배포가 돈다."*
**매 push 마다 CHANGELOG 를 갱신해 별도 커밋으로 올리면 배포가 한 번씩 더 돈다.** 처리 방향은 개발 세션 판단:

1. push 훅에서 **그 커밋에 포함**시킨다 (추가 커밋 없음)
2. Cloudflare build watch paths 에서 **`docs/` 를 제외**한다 (2026-08-13 에 이미 제안된 것, Master 판단 대기)
3. 모아서 하루 한 번 갱신

## 5. 함께 걸려 있는 미결 (Master 결정 대기 — 이 문서는 결정 후 02번으로 이어 적는다)

개발 세션 실측(2026-08-21): **`git log` 는 `index.lock` 을 만들지 않는다. `git status` 는 만들되 실패해도 넘어가며 `--no-optional-locks` 로 시도 자체를 막을 수 있다. `add`·`commit` 은 잠금이 필수.**
금지 범위를 ①현행 유지 ②`log`·`show`·`rev-list` 해제 ③②+`--no-optional-locks status` 중 어디로 둘지 **Master 결정 대기.**
